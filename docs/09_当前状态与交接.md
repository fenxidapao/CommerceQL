## 9. Phase B 已知坑（都是踩过的）

- **会话属主 fail-closed**：`get_session` 里属主缺失或不符都返回 `None` → 两个端点统一 404 `SESSION_NOT_FOUND`；**不得**改成 403 或在 detail 里区分"存在但不是你的"（会变成存在性枚举机）。新增 `get_turns` 调用点必须放在 `meta is None → 404` 之后。
- **注册默认关闭**：`AUTH_ALLOW_REGISTRATION=false`；开启仅课程演示。租户由服务端 `AUTH_REGISTRATION_TENANT_ID` 决定，客户端传 `tenant_id` 会被 DTO 拒绝。
- **登录限流**：ADMIN 桶 5 次/分钟/用户（IP 预认证）；冒烟时第 6 次 429 是**限流生效**，不是故障。错误文案统一"用户名或密码错误"，防枚举。
- **JWT 密钥只读挂载**：公钥与私钥都从 `deploy/secrets/` 只读进容器（`/run/secrets/jwt_{public,private}.pem`）——签发器在 API 进程内，私钥必须可用；两文件均不入库。宿主缺文件时 Docker 会建**同名目录**，表现为读 PEM 失败。
- **前端 token 只存内存**：刷新页面即丢登录态，是设计；不要顺手写 localStorage。
- **MSW 会拦截 `/sessions`**：`VITE_ENABLE_MSW=true` 时列表是 mock（曾出现"上个月华东区GMV环比"）。连真实后端必须 `VITE_ENABLE_MSW=false`。
- **Vite 端口残留**：停任务后子进程可能仍占 5173；先确认端口再重启，否则新任务起不来但旧服务继续用旧代码。
- **浏览器点击失败**：窗口隐藏时会报 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`；退路是 `evaluate_script` 里 `el.click()`，快照仍可用。
- **B0/SQLite 方言**：SQLite 不认 `::timestamptz`（B0 6/30），v2 仍有 12 条 R14 方言缺口；不要靠改冻结集"修"。B0 harness 对每条 SQL 设 20s 超时（`o24` 曾跑出病理 SQL 卡死 >5 分钟）。
- **B2 的前置不是"改一行"**：`docs/06 §6.8` 明确前端本地导出绕过审计；必须后端生成 + 落审计。`app/cache/` 当前只有键和会话锁，结果缓存端口无实现。
