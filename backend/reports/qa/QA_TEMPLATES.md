# 验收窗口（QA）· 报告模板与表头（v1.0 · W7 起草，交给 QA 窗维护）

用法：QA 窗第一轮把这些表头复制进 `QA_LEDGER.md` / `TASK_BOARD.md` / `COMPLETENESS.md` / `GATE_LOG.md`，之后**只追加行**、不改历史行（订正写在 RELAY 最新段并 🔻 具名失效）。
⚠️ 排版三铁律：**表格单元里禁竖线**、**表格中间不许有空行**（GFM 会劈表）、**两张不同宽度的表要各自按表头取尺**。

## 一、`QA_LEDGER.md`：判据级台账（一行 = 一个判据/闸门）

| 对象（`U-xx` / `G-x` / `§16.5` 条号） | 判据原文位置（`07` 行号 + 版本） | 属主窗 | 最近一次实测（读数 + 作用域 + 面 + 谓词 + 分母 + 粒度） | 复算命令 | 复算时刻 + 当时 HEAD/镜像 | 资格三查（非空 / 静默期 / pre-fix 是否本就为 0） | 结论（达成 / 未达成 / `n/a` / `UNVERIFIED`） |
|---|---|---|---|---|---|---|---|
| 例：`U-129` 格2 | `07 §4.8` 第 N 行 v1.7.17 | W4（判据②） | 全库 5 / A 档子窗 4 / 新格 0（前置=1） | `…r23_thread_from_checkpoints.sql` 的 ⑰ + `-v win_a…` | 2026-10-01 13:0xZ / `8d170f2` / `0930r11` | 通过 | 达成（非空真） |

> 填写规矩：**读数一律带作用域**（本项目已实锤：同一判据的"基线"是"作用域 × 家族"的表，不是常数）；`n/a` 必须写原因（空作用域 / 无样本 / 靶子形状不含 / 未采）。

## 二、`TASK_BOARD.md`：任务单（发给别窗，经总控转发）

| 单号 | 交给谁 | 要什么（一句话，动词开头） | 判据出处 | 需要的证据形状 | 复算命令（QA 侧已跑通的） | 争用的单写者资源 | 花钱否（四件套） | 状态（待发 / 已发 / 待补 / 验收 / 结案） |
|---|---|---|---|---|---|---|---|---|

粘贴块模板（每窗 ≤10 行，总控照抄即可转发）：

```
[QA→<窗名> 第 N 轮 · 零花费 / 需批 ¥x] ① 复算结论：<达成 / 退回原因（差在哪一维：谓词/分母/面/粒度/时刻）>。
② 请补：要什么，判据 = `<07 行号>` 原文「…」，证据形状 = 文件:行号 + 命令 + HEAD + 时刻。
③ 我这面已跑：`<命令>` ⇒ `<读数>`（@`<HEAD>`，`<镜像/作用域>`）。
④ ⚠️ 提醒：这一列在 pre-fix 就为 0 ⇒ 单列"达成"不作数（见 §4.8 资格三查）。
⑤ 待总控：<要不要批 / 归谁裁>
```

## 三、`COMPLETENESS.md`：完成度三表

**A. 需求覆盖**（分母 = `01 PRD` 的 `FR-*` / `NFR-*` 条数，现读）

| 需求号 | 设计落点（`07` 节/行） | 实现落点（`文件:行号`） | 测试（文件 / 条数 @HEAD） | 文档（01–08 / `OVERVIEW`） | 状态（落地 / 部分 / 未启动 / 未验证） | 缺口一句话 |
|---|---|---|---|---|---|---|

**B. 缺陷与闸门**

| `U-xx` | 优先级 | 判据 | 最近读数（带作用域） | 结案条件 | 谁欠哪一步 | 状态（未结案 / 降级 / 观察中 / 结案） |
|---|---|---|---|---|---|---|

**C. 交付面**

| 要求出自 | 条目 | 当期证据（件号 + 时刻） | 状态 | 缺口 |
|---|---|---|---|---|

完成度写法（**必须带口径**）：
`落地 x / N（N = A+B+C 条目数现读，按条数不加权）；未验证 y；未启动 z；UNVERIFIED w —— 分母出自 <表>、计数命令 <find/grep 命令> @<HEAD>`

## 五、《落地报告》模板（终止前最后一轮）

```
# CommerceQL 落地报告（QA 窗，第 N 轮，2026-mm-dd HH:MMZ / 北京 HH:MM）
一、结论：落地 / 有条件落地（列条件）/ 未落地（列阻塞项）
二、§8 六条逐条对表（每条：判据出处 → 当期读数（带作用域与 HEAD）→ 复算命令 → 达成/未达成/n-a）
三、完成度矩阵终值（A/B/C 三表 + 口径）
四、残余风险清单（每条：现象 → 已量到的边界 → 未证的分支 → **下一次检查的触发条件**）
五、每类风险的建议复审节奏（哪些随秒漂移、哪些随 HEAD 漂移、哪些只在换镜像时变）
六、本窗自曝（我判错过什么、依据哪条被推翻）
```

## 六、给 QA 窗的"最容易踩的四条"（都来自本项目三十轮实锤）

1. **`exit 0` ≠ 跑完**；管道后的 `rc` 是过滤器的；收集期中止只有 ~3 秒。
2. **别拿别窗的散文当读数**：诊断别人的器件只有两种合法证据 —— 读它的代码，或复算它的产物。
3. **"0"要先问这一族本来会不会非 0**；无样本要记 `n/a` 不记 0；空作用域记 `NULL`。
4. **报数固定五件**：数 + 面 + 谓词 + 分母 + 粒度（run vs thread）；同名量不可互认、不可相加。
