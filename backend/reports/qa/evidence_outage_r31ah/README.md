## 二、结论一：出网路径**不是**差异来源

`out_path.txt` 实读（同一凭据、同一端点、同一时刻）：

| 路径 | 结果 |
|---|---|
| 直连（`trust_env=False`） | `http=200 t=0.27s` `models=['deepseek-flash','deepseek-v4-pro']` |
| 读环境代理（`trust_env=True`） | `http=200 t=0.15s` 同清单 |
| 显式指定环境代理 | `http=200 t=0.27s` 同清单 |

⇒ 本机环境里存在 **沙箱注入的 `http(s)_proxy`（`127.0.0.1:<port>`）**，但 **httpx 直连同样通**。
⇒ 「QA 走代理 ⟷ W8 直连 ⇒ 两者可达性不同」这个**假设被否**。本窗 R31ag 的「上游已恢复」
**不因路径差异而失效**。

`out_post.txt` 实读：

| 模型 | 次数 | 结果 |
|---|---|---|
| `deepseek-flash` | 2 | `http=200`，`t=0.67s / 0.76s`，`finish_reason=length`（`max_tokens=1` 所致，符合预期） |
| `deepseek-v4-pro` | 2 | `http=200`，`t=0.48s / 1.32s`，同上 |

⇒ **补全端点（POST，非只 `GET /models`）在两模型上 4/4 通、均 <1.4s**。

## 四、本诊断的**限制**（诚实登记，不得越界引用）

1. **单时刻**：全部读数取 `2026-10-15 16:2x +0800` 一个时点 ⇒ **只能证「此刻通」，不能证「这段时间都通」**。
   与 W8 的 2/2 失败**可以同时为真**（间歇性）。
2. **未复现 W8 的门**：本节**不跑** `--live` harness（那要花真钱）；因此**不能**判定
   「W8 的门下一次会不会过」，只能判定**供给侧此刻可达**。
3. **W8 的失败读数不可复算**：其两次冒烟的匣带与结果件**已删**（W8 自陈），
   `wall=8.335s`／`terminal_code=LLM_UPSTREAM_ERROR` 均**无盘上证据** ⇒ 本节**不判其真假**，只登记。
   ⚠️ 可交叉的一条：网关 `read=None`（**无读超时**）⇒ 8.335s 的失败**不可能是读超时**，
   只能是**连接层**或**上游返回 4xx/5xx**。
4. `probe_post.py` 的 `max_tokens=1` ⇒ **不覆盖**「长 prompt ＋ 大 `max_tokens`」的失败面
   （W8 的真实调用属后者）。
